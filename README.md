# 桌宠小深

基于 Electron + DeepSeek Harness (DSH) 的桌面宠物。她是鲸鱼娘女仆「小深」：会动、会饿、会犯困、会陪你聊天、帮你派活给 DeepSeek，也会陪你工作、玩小游戏、写日记、解锁照片。

当前版本：**2.0.0-rc.4**

## 功能

### 动画与互动
- 透明 WebM 动画：待机 / 点击 / 喂食 / 休息 / 睡觉 / 工作 / 游戏等
- 鼠标拖拽、点击互动、自主移动

### 聊天与派活
- 迷你聊天框：和小深日常对话
- 派活：通过 DSH 处理任务，完成后回到桌宠汇报
- 工作模式：完成工作获得金币与好感

### 养成
- 饱食 / 心情 / 精力 / 水分随时间衰减
- 商店：食物、饮品、礼物、娱乐
- 等级与好感度，解锁台词、工作与彩蛋

### 日记
- 采集当日活动时间线与互动事件，两步生成（先回顾要点，再写成日记）
- 可手动触发 / 删除；记忆卡记录重要瞬间

### 相册
- 时间型 / 事件型 / 数值型 / 节日型解锁
- 达成条件自动解锁，可回看全部与未解锁条件

### 小游戏
- 扫雷 / 五子棋 / 数独 / 2048 / 猜数字 等

### 日程与提醒
- 课程提醒（周次 / 单双周）、喝水提醒、备忘录

### 定制
- 名字、主人信息与生日、UI / 桌宠缩放、提示音、开机自启、台词池可编辑

## 运行

环境要求：

- Node.js 18+
- DeepSeek Harness 服务，或在设置页配置 API 提供商的 Base URL 与密钥

```bash
npm install
npm start
```

没有 DSH 服务时，动画、养成、小游戏等本地功能仍可使用；聊天、派活、日记需要 DSH 或 API 配置。

## 数据目录

桌宠状态与本地数据保存在用户数据目录（开发模式为项目内 `data/`），不会上传到网络。
