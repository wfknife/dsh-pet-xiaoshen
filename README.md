# 桌宠小深

一款基于 Electron + DeepSeek Harness (DSH) 的桌面宠物。

她是鲸鱼娘女仆「小深」，住在你的桌面上：会动、会饿、会犯困、会陪你聊天、会帮你派活给 DeepSeek，还能陪你工作、玩小游戏、写日记、解锁一张张专属照片。

## 功能

### 动画与互动
- 92 个透明 WebM 动画：待机 / 点击 / 喂食 / 休息 / 睡觉 / 工作 / 游戏等
- 鼠标拖拽、点击互动、自主移动

### 聊天与工作
- 迷你聊天框：和小深日常对话
- 派活：通过 DeepSeek Harness 处理任务，完成后回到桌宠汇报
- 工作模式：完成工作获得金币与好感

### 养成
- 饱食 / 心情 / 精力 / 水分，随时间衰减
- 商店：食物、饮品、礼物、娱乐
- 等级与好感度，解锁新台词、新工作、彩蛋

### 日记
- 自动采集当日活动时间线与互动事件
- 两步生成：先回顾要点，再写成日记
- 可手动触发、删除、忘掉今天
- 记忆卡记录重要瞬间

### 相册
- 73+ 张照片解锁
- 时间型 / 事件型 / 数值型 / 节日型
- 达成条件自动解锁，可回看全部与未解锁条件

### 小游戏
- 猜数字 / 扫雷 / 五子棋 / 数独 / 贪吃蛇 / 2048 / 接饼干

### 日程与提醒
- 课程提醒（支持周次 / 单双周）
- 喝水提醒
- 备忘录

### 定制
- 名字、主人信息、主人生日
- UI / 桌宠缩放
- 提示音
- 开机自启
- 台词池可编辑

## 运行

环境要求：

- Node.js 18+
- DeepSeek Harness（`127.0.0.1:3080`），或按向导配置 DeepSeek API

```bash
npm install
npx electron .
```

没有 DSH 服务时，动画、养成、小游戏等本地功能仍可使用；聊天、派活、日记需要 DSH 或 API 配置。

桌宠状态与本地数据保存在用户数据目录（开发模式为项目内 `data/`，安装后为系统用户数据目录），不会上传到网络。
