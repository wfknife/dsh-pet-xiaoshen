# 桌宠小深

基于 Electron + DeepSeek Harness (DSH) 的桌面宠物。她是鲸鱼娘女仆「小深」：会动、会饿、会犯困、会陪你聊天、帮你派活给 DeepSeek，也会陪你工作、玩小游戏、写日记、解锁照片。

当前版本：**2.0.0-rc.6**

## 功能

### 动画与互动
- 透明 WebM 动画：待机 / 点击 / 喂食 / 休息 / 睡觉 / 工作 / 游戏等
- 鼠标拖拽、点击互动、自主移动

### 聊天与派活
- 迷你聊天框：和小深日常对话
- 派活：通过 DSH 处理任务，完成后回到桌宠汇报
- 工作模式：完成工作获得金币与好感

### 养成
- 饱食 / 心情 / 精力 / 水分随时间衰减
- 商店：食物、饮品、礼物、娱乐
- 等级与好感度，解锁台词、工作与彩蛋

### 日记
- 采集当日活动时间线与互动事件，两步生成（先回顾要点，再写成日记）
- 可手动触发 / 删除；记忆卡记录重要瞬间

### 相册
- 时间型 / 事件型 / 数值型 / 节日型解锁
- 达成条件自动解锁，可回看全部与未解锁条件

### 小游戏
- 扫雷 / 五子棋 / 数独 / 2048 / 猜数字 等

### 日程与提醒
- 课程提醒（周次 / 单双周）、喝水提醒、备忘录

### 定制
- 名字、主人信息与生日、UI / 桌宠缩放、提示音、开机自启、台词池可编辑

## 运行

环境要求：

- Node.js 18+
- DeepSeek Harness 服务，或在设置页配置 API 提供商的 Base URL 与密钥

```bash
npm install
npm start
```

没有 DSH 服务时，动画、养成、小游戏等本地功能仍可使用；聊天、派活、日记需要 DSH 或 API 配置。

## AI 模型配置（聊天 / 日记 / 主动交流）

在 ⚙️ 设置 → 🧠 AI 模型 里配置，三种常见方式任选其一：

1. **本机 Ollama（免费、最省事）**：安装并启动 [Ollama](https://ollama.com)，在终端拉一个模型
   （例如 `ollama pull qwen3`），设置里类型选“Ollama（本地模型）”，点“获取模型列表”，再选模型即可。
   本机 Ollama 不需要 API Key。
2. **云端 API（DeepSeek / OpenAI / Anthropic / Gemini 或兼容中转）**：类型选“OpenAI 兼容”等对应协议，
   填入服务商控制台创建的 API Key，点“获取模型列表”，再点“使用此模型”。
3. **其它 OpenAI 兼容的本地服务**（LM Studio、vLLM、llama.cpp 等）：类型选“OpenAI 兼容”，
   地址填服务地址（通常以 `/v1` 结尾）；服务不校验密钥时密钥可留空。局域网服务也支持。

常见提示：
- 聊天面板/派活由 DeepSeek Harness 提供，其模型在 DSH 内配置；桌宠只负责检测连接，不会修改 DSH 的配置。
- 提示“服务要求认证”/“API Key 无效”：检查密钥是否粘贴完整、认证方式是否选对；本机无密钥服务可在
  高级设置里选“无需认证”。
- 提示“无法连接服务”：确认服务已启动、地址和端口正确（Ollama 默认 `http://127.0.0.1:11434`）。
- 提示“服务不识别该模型”：重新点“获取模型列表”选择，或手动填写模型名称。
- 提示“请求超时”：大模型首次加载可能较慢，稍后重试或调大超时。
- 切换服务后旧密钥会被清除（不会发往新地址），重新填写即可；模型和功能路由也需要重新选择，
  设置页会明确提示。


## 项目结构

```
deskpet/
├── main.js            # Electron 主进程（窗口 / 托盘 / IPC / DSH 桥）
├── preload.js         # 渲染层桥接（受限 API）
├── renderer/          # 渲染层
│   ├── pet.js         # 桌宠主逻辑
│   ├── anim/          # 透明动画资源
│   ├── photos/        # 相册照片
│   ├── dialogue/      # 对话与模型网关
│   ├── diary/         # 日记
│   ├── life-context/  # 生活情境
│   ├── memory/        # 记忆
│   ├── perception/    # 感知（前台应用与媒体）
│   └── ...
├── build/             # 构建与打包配置
├── package.json
├── LICENSE
└── THIRD-PARTY-NOTICES.md
```

## 数据目录

桌宠状态与本地数据保存在用户数据目录（开发模式为项目内 `data/`），不会上传到网络。
